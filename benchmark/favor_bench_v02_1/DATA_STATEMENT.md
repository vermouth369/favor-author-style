# Data Statement

This supplement prioritizes privacy and platform compliance over raw-text redistribution.

The package contains protocol assets, anonymized split specifications, aggregate statistics, schemas, and artificial toy examples. It does not contain raw author text, social-media handles, original author identifiers, original document identifiers, or author-linkable generated continuations.

Anonymous identifiers are stable inside this release only. The reverse mapping
is intentionally withheld from the public repository and release assets.
