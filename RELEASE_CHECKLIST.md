# Public-release checklist

- [x] Repository created independently from the private research worktree.
- [x] Raw text, author handles, private mappings, checkpoints, and logs excluded.
- [x] Public ASCE/classifier configuration included.
- [x] Data-preparation and privacy-boundary documentation included.
- [x] ASCE architecture, scale, margin, and epoch settings aligned.
- [x] MIT License added for original repository code.
- [x] Replace camera-ready metadata placeholders with the final author order,
      affiliations, venue/year, and contact addresses. The paper URL/DOI and
      page range are pending publication of the proceedings record.
- [x] Add `CITATION.cff` and a provisional `To appear` BibTeX entry.
- [x] Run the final manifest, syntax, privacy, and secret scans, including both
      original release archives.
- [ ] Push to the Private GitHub repository and inspect the rendered README.
- [ ] Change repository visibility to Public.
- [ ] Create GitHub release `v1.0.0` and attach the two original archives.
